## Methodology

The design-docs approach follows the **Design Docs Handbook**, drawn from Dex Horthy / HumanLayer's **"Why Software Factories Fail"** (wsff) planning flow, with the deep-module framing from Matt Pocock's `codebase-design`, and cross-checked against GitHub **Spec Kit**, Amazon **Kiro**, and Harper Reed's LLM codegen workflow.
